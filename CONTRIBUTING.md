# Como contribuir

Obrigado pelo interesse no **Bisturi Clips**.

## Por ora: só Issues

- **Achou um problema?** Abra uma Issue com o modelo **Problema**.
- **Tem uma ideia?** Abra uma Issue com o modelo **Ideia**.
- **Falha de segurança?** Não use Issue pública: veja o [`SECURITY.md`](SECURITY.md).

Antes de abrir, procure nas Issues já existentes (abertas e fechadas) e leia as perguntas frequentes do [`README.md`](README.md).

## Sobre o código

O código deste projeto é mantido numa **oficina privada**; este repositório é a cópia pública de cada versão. Por isso:

- Uma Pull Request aqui **não é mesclada diretamente**. Toda contribuição (Issue ou PR) é **avaliada** e, se aceita, entra na **versão seguinte**, passando pela oficina.
- Se quiser mexer no código mesmo assim, abra antes uma Issue contando a ideia, para não gastar trabalho à toa.
- Não cole na Issue o seu `config.toml`, links privados, tokens, SteamIDs ou caminhos com o seu nome de usuário.

## Regras do projeto

- Português do Brasil, simples e curto, nos textos da tela e nos documentos.
- O programa roda no computador de quem usa e **nunca** executa comando livre de FFmpeg: a IA só gera um plano validado.
- Não envie vídeos, demos, músicas com direitos autorais nem material do jogo.
- A licença é a [MIT](LICENSE); veja os [créditos](CREDITOS.md) das peças de terceiros.
